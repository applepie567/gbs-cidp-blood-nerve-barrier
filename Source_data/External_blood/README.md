# External blood plot sources

These CSV files provide the donor scores and full statistical tables for Figures 3, S10 and S11, plus the targeted synthesis in Table S5. Sample and technical column mappings are also included. The panel index refers to the matching filenames in this directory (originally `results/` inside Supplementary Data 5).

Supplementary Data 5 contains the all-gene donor pseudobulk counts, full bulk inputs, gene annotations, all secondary tests, cell metadata, extraction and analysis code, source URLs and checksums. Scores use a separate standardisation within each population; they are not directly comparable across populations or between acute and paired analyses.
