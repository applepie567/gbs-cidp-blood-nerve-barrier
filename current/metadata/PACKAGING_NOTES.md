# Packaging notes

The supplied Additional_file_4 exploratory-extension ZIP lacked a complete ZIP directory. Its content was recovered from the preceding complete package and the recorded final text changes. Existing quantitative CSVs and analysis scripts in that recovery were unchanged. The current package was then assembled from the recovered extension, current manuscript images, the author archive's retained aggregate analyses and the pinned live repository baseline. This ZIP is independently checked for extraction and SHA256 integrity.

Binary SQLite range caches are excluded and can be downloaded by the retained public reader. No mapping from instrument runs to diagnosis was invented. Supplementary files 1–3 and the manuscript are the current supplied versions, copied without content changes.
