# Version 2.0.0

## Current analytical design

- Reorganized the study around blood, CSF and peripheral-nerve immune compartments.
- Retained acute-GBS blood cohort analysis and biological-sample pseudobulk analysis.
- Added published GBS CSF proteomic evidence with explicit inference-level labels.
- Added donor-resolved CIDP peripheral-nerve analysis.
- Added localization of published CIDP genetic candidates to Schwann cells, B cells, macrophages and blood-nerve barrier endothelium.
- Added release-level scripts for CSF evidence, genetic localization, cross-compartment synthesis and workbook export.
- Replaced the previous six-figure layout with five publication figures.
- Added a complete 19-sheet source-data workbook and machine-readable CSV exports.

The genetic component prioritizes gene-cell combinations for functional validation. It does not establish direct clinical drug targets.
