# Version 2.1.0

This release aligns the repository with manuscript v37 and the public aggregate-data supplements dated 6 September 2026.

- Updates the manuscript, five main figures, two supplementary figures and three tables to the final analyses and layout.
- Includes blood synthesis and leave-one-cohort-out estimates, eight published CSF coefficient pairs and pooled estimates, genetic localization bootstrap summaries, nerve-module and correlation summaries, and attributed external tissue evidence.
- Supplies the 30-sheet public workbook: 28 retained aggregate/documentation sheets plus original-input and reconstruction registers. The register contains 19 original-input/source records with filenames where recorded, accession numbers and links.
- Moves detailed source information to the supplements while keeping the manuscript availability statement concise.
- Omits donor/participant-level intermediates and sample-level JSON copies from the current tree; adds local-output exclusions to `.gitignore`.
- Provides a default aggregate verification workflow. Full donor-table calculation requires explicit local inputs. Genetic donor-cell reconstruction from raw matrices is not supplied, as explained in the appendix.
- Removes obsolete preprint outputs, duplicate scripts and superseded documents from the current branch. Historical tags, commits and archives remain unchanged.

Aggregate numerical results and all seven manuscript images are preserved. Original data matrices were not rerun for this update. Original input download dates and checksums were not recorded and are not fabricated. Historical v36 reproduction reports are retained under `metadata/history/`; current checks write separate public verification reports.

The preceding Zenodo DOI, 10.5281/zenodo.22226674, identifies v2.0.0. It does not identify the present release; Zenodo archival status must be checked separately.
