# Immune recruitment across blood cohorts and macrophage composition in inflammatory neuropathies

The current clean manuscript, supplementary information, figures, source data and reproduction materials are in [`current/`](current/README.md). Use the two outer Word files in that directory. Earlier files elsewhere in this repository and within historical reproduction archives retain their original scope.

This package prepares version 2.5.0. It includes external blood reanalyses and an independent whole-nerve comparison with macrophage composition sensitivity analyses. The final editorial revision improves the presentation without changing statistical results. The independent tissue comparator is vasculitic neuropathy. Matched macrophage-specific CIDP versus CIAP replication remains unavailable.

After the release is archived, add its version DOI here. The previous v2.4.0 record remains at https://doi.org/10.5281/zenodo.22885750.

See [`current/README.md`](current/README.md) and Supplementary Data 1–6 for reproduction and source attribution. Supplementary Data 6 is expanded for browser upload; its large TIFF is compressed separately without loss.
