# Reproducibility

Run commands from the repository root unless a block explicitly changes directory.

## Figure-level reproduction (offline)

```bash
python -m pip install -r requirements.txt
python current/analysis/reproduce_figures.py --out rebuilt_figures
python current/analysis/verify_release.py
```

This regenerates all twelve figures from included aggregate estimates, anonymous clinical coordinates, and published observations. Outputs go to the requested directory; the frozen manuscript images remain unchanged. `python current/analysis/export_figure_sources.py` refreshes the per-panel CSVs from their included upstream tables and writes a JSON workbook payload. It does not overwrite the frozen Excel file.

Current source tables and testing-family notes are indexed in `figure_source_data/INDEX.csv`. The source workbook is a static export of those CSV tables; formulas are not needed to recover the recorded numerical estimates.

## Current extension from public primary inputs (online, optional)

```bash
cd current
python analysis/download_inputs.py --manifest source_data/public_input_manifest.csv --out input
python analysis/csf_extension.py --out recomputed --source recomputed_source --legacy legacy_reference
python analysis/nerve_programs.py --raw input --legacy legacy_reference --out recomputed --private local_intermediates
python analysis/clinical_exact_sensitivity.py --private local_intermediates --out recomputed --legacy legacy_reference
python analysis/normal_bnb_reference.py --input input/normal_bnb/GSE107574_fpkm_gene_expression_values.xlsx.gz --out recomputed
python analysis/genetic_sampling_audit.py --metadata input/metadata_all.csv.gz --out recomputed/genetic_Bcell_sampling_audit.csv
```

The sequence/count files are downloaded from GEO and remain under their original terms. Original full donor metadata and matrices are not duplicated in the figure-source distribution. Intermediate donor-linked data are generated locally. The raw-input reconstruction was performed during the earlier analysis; preparation of this release rechecks the supplied tables and plotting workflows, not every primary-input pipeline.

The original blood and nerve pipeline is archived under `original_analysis/`. Its complete raw-input requirements and CLI options are stated in the individual scripts and source manifests. Some historical checks require the original donor intermediate files; use the current `verify_release.py` for the checks possible directly from this public package. The earlier 89-test multiplicity output remains historical; the current 91-test family is explicitly included under `followup_20260921/results/` and in the figure workbook.
